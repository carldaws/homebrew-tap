# Carldaws Tap

## How do I install these formulae?

`brew install carldaws/tap/<formula>`

Or `brew tap carldaws/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "carldaws/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
